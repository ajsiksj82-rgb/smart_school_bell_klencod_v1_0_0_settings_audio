# الجرس المدرسي الذكي — Smart School Bell

مشروع Flutter باللغة العربية، إصدار 1.0.0.

## وظائف هذه الحزمة
- إدارة المدارس والمباني، الأحداث في الجدول، الإجازات، وسجل التشغيل.
- متابعة الحصة الحالية والوقت المنقضي والمتبقي.
- استيراد ملف صوت للجرس من صفحة الإعدادات، تجربة الصوت وإيقافه وحذفه.
- حفظ الصوت المختار محليًا في مساحة التطبيق.
- صفحة إعدادات ومعلومات المطور.

## بناء التطبيق
استورد جذر المشروع في Klencod IDE ثم شغّل بناء Android APK. يمكن أيضًا البناء باستخدام `flutter pub get` ثم `flutter build apk --release`.

## مهم
الجدولة الحالية لا تعمل كخدمة خلفية موثوقة عند إغلاق التطبيق. يلزم استكمال خدمة Android للإنذارات واختبار قيود البطارية والأذونات قبل الاعتماد عليه كجرس مدرسي.

راجع `STATUS_AR.md` و`ICON_GUIDE_AR.md`.
